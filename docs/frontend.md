# Frontend

> 状态：Current（后续 Phase 小节为历史增量记录）

解析工作台只临时展示阶段进度，不展示或长期保存解析 block/chunk 事件；任务结束后应通过
文档详情和切片页面查看最终结果。上传选择器不设置文件大小限制。
> 维护日期：2026-07-15

前端使用 Vue 3、Vue Router 和 Vite，用户可见文案保持中文。

当前质量入口：

```bash
npm run typecheck
npm run lint
npm run test
npm run check
```

图片媒体地址统一通过 `src/utils/media.ts` 解析，页面不应各自维护 `url/image_url/path/base64`
兼容规则。普通 chunk API 只返回向量预览，不返回完整 embedding。

## WeKnora 对齐 Phase A 前端展示

前端保持现有页面结构，仅在详情页补充关键兼容字段：

- 文档详情页展示：知识 ID、来源、渠道、启用状态、处理时间。
- 切片详情页展示：知识 ID、起始位置、结束位置、前置切片、后置切片、切片类型、父切片、上下文标题、内容 Hash。

本阶段未新增复杂 UI，也未实现结构感知 chunker、parent-child chunking 或 WeKnora RRF 检索展示。
 
## WeKnora 对齐 Phase B 前端展示

chunk 列表页已展示结构化字段：序号、切片类型、起始位置、结束位置、上下文标题预览、内容预览、状态。

chunk 详情页继续展示：切片类型、起始位置、结束位置、前置切片、后置切片、父切片、上下文标题、内容 Hash、metadata_json。

## WeKnora 对齐 Phase C

- 本地检索调试页展示文档标题、文件名、起止位置、切片类型、上下文标题、命中文本和元数据。
- 模型配置页的 Embedding 测试支持输入测试正文、文档标题和上下文标题，并展示模型、维度、输入长度和输入预览。

## 切分配置与向量状态修复

## DCP-4R 字段级索引准入

- 文档详情的向量状态新增“索引准入”卡，展示准入决策覆盖数、内容来源、通道状态、旧视觉 OCR
  skip 恢复数、残留数和当前跳过原因。
- 切片详情展示 `content-admission-v2` 决策、正常索引来源、辅助保留来源及每个通道的字符数和预览。
- `visual_ocr` 进入 shadow 时仍保留在 Chunk/artifact metadata 中；caption、VLM、可靠正文和图片
  继续参与检索。
- 前端只展示后端已持久化的准入诊断，不在浏览器中重复判断 OCR 质量。

## DCP-0.1 数据集验收

解析评测首页提供“DCP-0.1 数据集验收”入口，路由为
`/parse-eval/datasets/document-profile`。页面展示总场景、对抗场景、混淆组和数据门禁，可按
能力或关键词筛选 case，并展开查看 gold、当前 replay actual、差异与复现产物。该页面不允许把
合成覆盖率解释为真实 MinerU 准确率。
